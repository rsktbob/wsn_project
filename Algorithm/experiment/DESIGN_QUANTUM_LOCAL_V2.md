# 第二版：量子啟發式局部感測等級探索

這是 classical CPU 上的 quantum-inspired 機率更新，不使用量子硬體、糾纏或量子加速，也不宣稱是原始 QEA/QEA3。沒有離線訓練或神經網路，但有**節點自己的線上學習**。`training=False` 指不進行獨立模型訓練階段，不代表角度永遠不更新。

## 保留與改變

保留第一版的控制能量預留、是否參與協調、覆蓋宣告/ACK、候選競爭分數、容量預留路由、感測/資料成本與 lifetime 判定。原 `local_scheduling.py`、`reserved_routing.py`、`run_local_schedule.py` 與 `State/SensorEncoding.py` 都不修改。

只改各節點提出感測等級的方式：85% 機率選原本局部貪婪最佳等級；15% 機率從節點維護的機率模型取樣另一個合法候選（也可能抽到同一個等級）。取得局部執行結果後，更新自己的模型。

`probabilistic_scheduling.py` 保存原協調流程的獨立副本，只加入 instance policy hook，不做全域 monkey-patch。測試確認 greedy hook 與原版的 levels、next_hops、tx_load、控制耗能、訊息數和承諾紀錄一致。

## 編碼與角度

目前正感測等級為 1～5，每個節點維護 **4 個角度**，100 個節點共 400 個角度，沒有族群。關閉（0）仍由既有是否參與/是否取得覆蓋責任決定，**不是第五個角度或額外抽樣動作**。

對 K 個正等級使用 K−1 個條件 Bernoulli gates：

- `p_j = sin(theta_j)^2` 是該 gate 成為 1 的機率。
- 第一個 0 所在位置決定類別；全部為 1 時選最後一類。
- 初始化 `p_j = (K-j-1)/(K-j)`，使 K 個正等級的先驗機率相同。
- K=5 時 gate 機率為 `[4/5, 3/4, 2/3, 1/2]`，五個類別各為 1/5。

程式先計算同樣的類別機率再直接取樣，不需要真的建立 bit 字串。每次只保留「高於目前等級、仍有新覆蓋目標、能量可負擔」的候選，重新正規化機率。它和先前全域 QEA 的 1400 維 sensor/priority encoding 不同，也完全沒有修改那套編碼。

所有角度單位都是弧度。每節點使用獨立 seed stream；收到相同局部狀態時沿用已取樣提案，避免模擬器處理無關事件時免費重抽。一次 lifetime 內跨排程階段保存模型，每次新的 map/seed 實驗才重設。

## 局部回饋，不使用全域最佳解

路由建立後，每個啟用節點取得自己的：等級、是否收到成功選路確認、剩餘能量、每時槽感測+資料收發成本、本次控制成本。模擬器把這些量投影成 `LocalFeedback`，政策不讀全網 coverage、fitness 或完成的 lifetime。

令 `h = (自身能量 − 自身控制成本) / 自身每時槽成本`。若沒有路由確認，或不足以服務一個 slot，令 h=0。回饋：

`r = h / (h + 100)`

100 是固定的時槽正規化尺度，未依地圖調參。這是自己的**預估可服務時間**，不是實際全網存活時間，也不是整條路徑瓶頸。

每個節點保存回饋移動平均 b，初值 0.5：

`advantage = r − b`

`b ← 0.8 b + 0.2 r`

若同一個節點在一輪多次升級，僅針對最後採用的等級給一次回饋，不把全部中間升級重複記功。即使該等級是 greedy 分支選出的，也會更新對它的經驗。未啟用的節點不更新。

此回饋有侷限：能量會隨時間下降，歷史平均未必可直接代表當前條件；其他節點交付的轉送負載也會影響結果。這是簡單局部學習原型，沒有收斂或全局改善保證。

## 量子更新與對照

對觀察到的類別 k，只更新表示該類別所需的前綴 gates；第一個 0 後面的 gates 不更新。

量子組：

`theta_j ← clip(theta_j + 0.01*pi × advantage × (2*target_bit_j−1))`

角度界限使 gate 機率保持在 0.01～0.99（大類別數時相應縮小下限）。正 advantage 提高已選類別的機率，負 advantage 降低它。這不是每次一律加 0.01*pi，而是乘上有正負的 advantage。

傳統機率組：

`p_j ← clip(p_j + 0.05 × advantage × (target_bit_j−p_j))`

使用同一前綴 mask、回饋、機率下限與探索比例。它不經由旋轉更新，記錄的 angles 僅由 arcsin(sqrt(p)) 還原，方便稽核。

隨機對照組保留相同 15% 探索與均勻正等級先驗，但完全不更新機率。原版 greedy 不做機率探索。

**四組比較才能區分貪婪、隨機探索、一般機率學習和角度更新。** 量子步長與傳統更新率未做等效校準，因此結果不能證明某種機率參數化本質上較強。各節點實際只經歷少量重新排程，學習次數也有限。

## 公平性及通訊限制

回饋僅用原路由協定已提供的確認與節點自身流量/能耗帳，不額外傳播全網 reward；沒有新增訊息類型或忽略它的傳输成本。不同提案會造成不同承諾/路由訊息數，仍照實扣電。

沿用第一版：理想可靠直接控制通訊、已知重疊鄰居與醒睡名單、序列化事件競爭。未計探索、同步、碰撞重傳或運算能耗；排程完成後仍可能覆蓋/選路失敗，未加入中央修復或全域挑選最好的隨機樣本。

## 檔案與重現

- `quantum_local_v2.py`：節點角度/機率、局部提案與回饋。
- `probabilistic_scheduling.py`：原協調流程加局部政策插入點。
- `test_quantum_local_v2.py`：六項測試。
- `run_quantum_local_v2.py`：固定參數、六圖配對 lifetime 實驗。

從 codes/2027WSN 執行：

```bash
python -B Algorithm/experiment/test_quantum_local_v2.py
python -B Algorithm/experiment/run_quantum_local_v2.py --runs 5 --workers 3
```

每圖 greedy 跑一次，其他三組各跑 seeds 7～11，共 96 次完整實驗，控制成本全部計入。沒有 lifetime 上限；若碰到 max_rounds 則報未完成，不能當成真實失效。逐段保存局部 reward、角度、機率、路由與能量，並驗證角度/機率一致性、覆蓋、合法鏈路、無環與能量守恆。

全部產物在 Algorithm/experiment。實驗前後核對外部來源及原版檔案 SHA256；演算法快照與參數記錄在 results/quantum_local_v2_six_maps。
