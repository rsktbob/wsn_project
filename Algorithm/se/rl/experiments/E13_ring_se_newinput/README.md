# E13：E12 結構換新輸入（Net13）

- 狀態（10/26）：b1000 Net13（plain_delta、soft τ=1、全 0 也訓練）訓練＋lifetime 評估完成；準確度略低於 E12，lifetime 對 E07／E08／E12 全 ns。
- 動機（使用者 10/26）：拿掉能由其他輸入推得的特徵；補上原始基因、座標、排層／路由 cost 分開；
  個數用原始值交給 z-score，不再除以「這個解的全網最大」（S、G 才可比）、不截上限（E07 的 /5、/3）。
- 網路結構和 E12 RelFlagNet 相同，只換輸入維度。

## 輸入（env13.py）

token 24 ＝ sensor 本身 4 ‖ S 10 ‖ G 10（z-score）：

- sensor 本身：剩餘電量 / 初始電量、(x − BS x) / 邊長、(y − BS y) / 邊長、離 BS 距離 / 邊長
- 每個解：等級基因 /9、priority 基因 /9、解碼後等級 /5（0 ＝ 關）、子樹大小、跳數、排層 cost / 初始電量、
  路由 cost / 初始電量、緊迫度、覆蓋 target 數、只有它覆蓋的 target 數

候選 9：起點、終點、長度（/ N）‖ 範圍外路徑經過範圍內的開啟 sensor 數 / N（S、G）‖ 範圍內覆蓋的 target 範圍外無備援比例（S、G）‖
瓶頸：範圍內有效差異 sensor 的緊迫度總和（S、G）。

全域 7：活著 sensor 平均電量、S／G 覆蓋率、最短壽命差、S／G 開啟數 / N、兩解基因不同的比例。

和 E12 比拿掉：開關、是否轉送節點、轉送量（＝ 400 ×（1 ＋ 子樹大小））、3 個差異旗標、候選「是否跨段」、
全域的搜尋進度、停滯、fitness 差距排名。

## 資料

`collect13.py` 用 E07 collect 相同的地圖、seed、標註段重跑原版 ring_se，只收新輸入（不偷看子代，約 7 分鐘 200 張）；

標籤沿用 E07 results/data/b1000，②③⑤ 沿用 E08 results/data/b1000。

## 結果

| E12 RelFlagNet | 62.60% | 54.10% | 61.40% |
| **E13 Net13** | **61.97%** | **53.33%** | **60.74%** |
