# E07 / supervised：學作弊版選哪個候選

- 演算法：監督式分類（softmax 交叉熵），不接 RL（使用者 10/19：和 D3QN 分開）
- 框架：PyTorch 2.x
- 程式：`../collect.py`（標籤）、`../train_sup.py`；結果：`../results/supervised/seed{seed}/`
- 網路圖：`network.svg`

## 0. 目前用法（10/22 起）

`../train_sup.py --budget 1000 --maps 140 --label diff_cur --val --epochs 20`：資料 `results/data/b1000/`（train RLTRAIN01–140 取前 N 張、val 141–170），
回歸 `diff_cur`（差異獎勵 ÷ 這一回合尺度，Huber），驗證早停、用 best.pt。test（171–200）用 maps_test.json 跑 lifetime。
`--label oracle_choice` 是「學作弊版的選擇」（交叉熵，下面 1–5 節記錄的就是這個版本，結果較差）。

## 1. 資料

`../collect.py`：RLTRAIN01–30 每張用**原版 ring_se（4 選 1 隨機）推進**，每段預算 10000，從滿電跑完整 lifetime；
每 3 段標一段，起點依地圖錯開（第 i 張圖標段號 ≡ i mod 3）。標的段**作弊版只標答案**：每組交易偷看 4 個候選
「只交換」的結果（不計預算、不更新最佳、不用演算法亂數 → 推進和沒標時完全相同；冒煙測試已確認 lifetime 一樣）。

## 2. 標籤

作弊版會選的候選：只交換的一般 Δ ＝ max(0, f(c1) − f(S)) + max(0, f(c2) − f(G)) 最大的，同分再比 f(c2)（同 E06 作弊版）。
每組交易都有答案（4 個 Δ 都是 0 時就是 f(c2) 最大的）。另存 4 個候選的 Δ、f(c2)、E06 差異獎勵版標籤（備用）。

## 3. 輸入、輸出、網路

輸入同實驗層 README 第 3 節；輸出 4 個分數，softmax 成機率，選最大。

| 部分 | 輸入 → 輸出 | 參數量 |
| --- | --- | --- |
| φ（每顆 sensor） | 25 → 64 → 64 | 5,824 |
| 候選 MLP | 148 → 128 → 64 | 27,328 |
| 分數頭 | 64 → 1 | 65 |

總參數量 33,217。

## 4. 訓練設定（`../config.json`）

- 交叉熵 −log π_(作弊版選的候選)，全部交易都用。
- Adam lr 3e-4（cosine 衰減到 0）、L2 1e-5、batch 256、梯度裁剪 10、**固定 5 個 epoch、不早停、不切驗證**；評估用 `final.pt`。
- 每 epoch 在固定 20 萬組訓練交易上記：交叉熵、和作弊版一致的比例（隨機 25%）、選到的一般 Δ ÷ 最大一般 Δ（只算至少一個 Δ > 0 的交易）、4 個位置被選比例。

## 5. 結果

最後 epoch：訓練交叉熵 0.948、和作弊版一致 62.4%（Δ > 0 的交易只 34.2%，全 0 的交易 76.8%）、選擇比例 [0.12, 0.14, 0.23, 0.51]。
lifetime（MAP01–06 × seed 7–11、預算 10000）1030.5，對同場 ring_se 1064.1 **−3.15%**（6/24，p=.0002）。詳見實驗層 README 8.1。
