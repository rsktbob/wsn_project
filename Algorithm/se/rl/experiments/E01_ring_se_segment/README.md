# E01_ring_se_segment

- 日期：2026-10-13
- 狀態：**訓練中**（天花板測試已完成；D3QN DQfD 式 seed 0 訓練中，2026-10-13）
- 基底演算法：`ring_se`（Ring_SE，SensorEncoding，n8 h4 w8 μ0.4，EN 更新，**每組交易各自均勻隨機選段**）

## 1. 目的

Ring_SE 每回合讓每組 searcher-good 交易**均勻隨機**選一個 ring 區段，在那段交換、突變。
這個實驗要回答：

1. **學到的策略選段，能不能讓 lifetime 比隨機選段更長？能拿到天花板（作弊版）的多少？**
2. 加入老師的示範（模仿學習，DQfD 式）有沒有幫助？
3. 考慮後續回合（γ > 0）有沒有比只看眼前（γ = 0）更好？

比較對象（全部是 ring_se）：

| 版本 | 說明 |
| --- | --- |
| `ring_se` | 原版，每組隨機選段（下限） |
| `linucb_ring_se` | 每組交易用 LinUCB 選段（線性 bandit 基準） |
| 作弊版 `oracle/` | 偷看 4 段只交換的結果選段（天花板） |
| 純模仿 | 只用老師示範的大邊界損失 |
| D3QN／Rainbow | 只用 TD 損失、不用示範 |
| **D3QN／Rainbow ＋ DQfD 式模仿** | **主方法**：TD 損失＋大邊界模仿＋示範預訓練＋示範永久留在 PER |
| γ = 0 消融 | 主方法改成只看眼前一步 |

D3QN（`d3qn/`）與 Rainbow（`rainbow/`）各自用同一個網路跑這些訓練方式，網路、輸入、輸出、獎勵見各自的 README。

## 2. 問題設定（所有 RL 演算法相同）

- **決策單位**：每回合每組 searcher-good 交易（8 × 8 = 64 次決策／回合）。預算 1000 一段約 8 回合。
- **動作空間**：4 個 ring 區段選 1（第 0 段最靠近 BS）。決策前先在每段用 Ring_SE 原本的 80/20 規則各抽一個候選範圍；
  隨機選等於原版 ring_se 的分布。交換、突變、EN 更新都和 Ring_SE 相同。
- **網路**：經典 Dueling（Wang et al., 2016）——4 段特徵依段號串成一個輸入（60 維），一次輸出 4 個 Q，
  第 k 個輸出固定代表第 k 段。
- **主設定 γ = 0.5、n = 3**；轉移＝同一個 searcher 編號、同一個 good 位置的下一回合（good 可能被別的子代換掉，轉移有雜訊）。
- **一個 episode**：一段最佳化（lifetime 中的一次重新最佳化），預算 1000（主要）；3000 當延伸。
- **環境**：fitness v3、SensorEncoding（v3 解碼、無 0.5 偏移）。
- **地圖**：訓練 `maps/maps_100100100_train.json`（200 張，另切 10 張當驗證）；測試 MAP01–06（已確認和訓練圖座標都不同）。
- **訓練快照**：先在訓練圖上用 ring_se 跑完整 lifetime，存下每次重新最佳化時的電量狀態；每個訓練 episode 從中均勻抽一個。

## 3. 老師（示範資料）

- 老師＝作弊版：每組交易偷看 4 段**只交換、不突變**的結果（不計預算），選 Δ 最大的段（同分比 f(child2)），再照常突變。
  只交換的結果是確定的，所以老師的選擇不含突變運氣。
- 在訓練圖快照上跑作弊版，存下每組交易的 (s, a_E, r, s′) 當示範。
- 照 DQfD：示範是固定的一批，線上訓練不再問老師，所以線上訓練的評估量和一般 ring_se 相同。

## 4. 實驗步驟

1. **天花板測試**（已完成，`oracle/`）：見第 7 節。
2. **容量測試**：用示範資料做純模仿（大邊界損失），共用層寬度 64／256／1024，看「選到老師那段」的比例
   （訓練／驗證），判斷是網路太小還是輸入資訊不夠。
3. **計時**：先量特徵計算＋推論的時間。
4. **主實驗**：第 1 節的版本 × {D3QN, Rainbow}，每個訓練 **3 個 seed**。

## 5. 評估

- MAP01–06 × **seed 7–16（60 場）**，預算 1000（主要）、3000；基準（ring_se、linucb_ring_se）同 seed 重跑。
  ring_se 的 CV 約 7%，同一分布不同亂數就有約 2% 的差異，所以用 60 場。
- 成對 Wilcoxon（同地圖、同 seed），報平均、CV、最差場、各地圖平均；訓練 seed 間報平均與範圍。
- 主要指標之一：**拿到天花板的比例** =（RL − ring_se）÷（作弊版 − ring_se）。
- 額外記錄：每步獎勵平均、4 段被選比例、和老師的一致率、每段額外時間；選段如果全擠在同一段要特別標出。

## 6. 不在這個實驗做的

- **用最終 fitness 當獎勵**：一段 8 回合 × 64 = 512 個決策共用一個分數，Q-learning 很難分配功勞；另開實驗。
- **每顆 sensor 各自編碼（DeepSets／圖網路）的輸入、段之間加注意力**：容量測試顯示需要時另開實驗。

## 7. 結果

**天花板（作弊版，MAP01–06 × seed 7–11，30 場，同 seed 成對）**：

| 預算 | ring_se（每組隨機） | 作弊版 | 差異 |
| --- | --- | --- | --- |
| 1000 | 899.9 | 982.1 | **+9.1%**（29/1，p < 0.001） |
| 3000 | 997.0 | 1055.5 | **+5.9%**（28/2，p < 0.001） |

結果檔：`experiment_results/e01_oracle_6maps_eval1000_02`（`_02` 才是現行版本；不帶 `_02` 的是被取代的舊版殘留）、
`e01_oracle_6maps_eval3000`。

ring_se 每組隨機選段和舊版（每 searcher 一段）lifetime 在雜訊內：1000 −1.4%、3000 +0.3%、10000 −0.2%（都 ns）。

RL 部分：尚未開始。

## 8. 結論與下一步

天花板在預算 1000 有 +9%，值得做 RL；天花板隨預算變大而縮小，主戰場是預算 1000。下一步：容量測試。
