# E01 / D3QN（含 DQfD 式模仿）

- 演算法：D3QN（Double DQN＋Dueling；原理見 `../../../algorithms/d3qn.md`）。
  模仿版照 **DQfD**（Hester et al., AAAI 2018）：同一個網路，多一項大邊界模仿損失、示範資料預訓練並永久留在 PER 回放。
- 同一個網路跑三種訓練（網路完全固定，差異只在損失與資料）：

  | 版本 | 損失 | 示範資料 |
  | --- | --- | --- |
  | D3QN | Double DQN 1-step ＋ n-step ＋ L2 | 不用 |
  | **DQfD 式（主方法）** | Double DQN 1-step ＋ n-step ＋ 大邊界模仿 ＋ L2 | 預訓練＋永久留在 PER |
  | 純模仿 | 大邊界模仿 ＋ L2 | 只用示範 |

- 啟用的元件：Dueling、Double DQN、target network、n-step、PER（DQfD 版與示範資料一起用）；不用 Noisy、Distributional
- 框架：PyTorch（版本：2.14.1）
- 狀態：**訓練中**（DQfD 式 seed 0；程式 env.py、snapshots.py、collect_demos.py、d3qn/agent.py、d3qn/train.py、d3qn/config.json）

## 1. 輸入狀態

**經典 Dueling 的輸入：一組交易的整個狀態一次輸入**，4 段的特徵依段號固定位置串接（位置本身就代表第幾段，
所以不需要區段編號 one-hot）。

```
輸入 60 維 = 段 0 特徵 14 ‖ 段 1 特徵 14 ‖ 段 2 特徵 14 ‖ 段 3 特徵 14 ‖ 全域 4
（第 0 段最靠近 BS；每段的特徵算在該段的候選範圍內）
```

每段 14 維（第 k 段的候選範圍內；有效／無效差異、開啟與否都看解碼後的結果）：

| 特徵 | 維度 | 怎麼算 | 正規化 |
| --- | --- | --- | --- |
| 有效差異數分格 | 4 | searcher 與 good 基因不同、且任一方有開的 sensor 數，分成 0／1–2／3–4／≥5 | one-hot |
| 無效差異數 | 1 | 基因不同、但兩方都沒開的 sensor 數 | min(x, 5) / 5 |
| 範圍長度 | 1 | 候選範圍 sensor 數 | ÷ 最長區段長度 |
| searcher 開啟比例 | 1 | 範圍內 searcher 有開的 sensor 比例 | 0–1 |
| good 開啟比例 | 1 | 範圍內 good 有開的 sensor 比例 | 0–1 |
| 最低電量 | 1 | 範圍內 searcher 有開的 sensor 的最小 E | E / E_max；沒有開的 sensor 時為 1 |
| 平均電量 | 1 | 同上，平均 | E / E_max |
| 瓶頸 sensor 數 | 1 | searcher 解中 E ÷ 耗能最低的 5 顆，有幾顆落在範圍內 | ÷ 5 |
| 耗能占比 | 1 | 範圍內 sensor 耗能 ÷ searcher 全網耗能 | 0–1 |
| 單一覆蓋 target 數 | 1 | 範圍內有開的 sensor 負責、而且只被一顆 sensor 覆蓋的 target 數 | ÷ 範圍內開啟數（上限 1） |
| 區段近期成功率 | 1 | **本 episode 內**這一段最近 50 次被選時「有改善」的比例（不跨 episode） | 0–1；沒紀錄時 0.5 |

全域 4 維：

| 特徵 | 維度 | 怎麼算 | 正規化 |
| --- | --- | --- | --- |
| 搜尋進度 | 1 | 已用評估 ÷ 預算 | 0–1 |
| searcher 停滯 | 1 | searcher 連續沒改善的回合數 | min(x, 20) / 20 |
| fitness 差距 | 1 | (f_good − f_searcher) 在本回合 64 組交易中的排名 | 0–1 |
| 全網電量 | 1 | 活著的 sensor 平均 E | E / E_max（代表 lifetime 階段） |

## 2. 輸出

- **4 個 Q 值，第 k 個輸出固定代表第 k 段**：Q(s, k) = V(s) + A(s, k) − mean_k A(s, k)。
- 選動作：訓練時 ε-greedy（DQfD 預訓練後 ε 從 0.1 降到 0.01；D3QN 版從 1.0 開始），測試時 argmax。

## 3. 獎勵與轉移

**每步獎勵**（每組交易一個）：

```
改善量 Δ = max(0, f(child1) − f(searcher)) + max(0, f(child2) − f(good))
Δ ≤ 1e-12 → r = 0                         （門檻避免浮點誤差級的改善）
Δ > 1e-12 → r = 0.5 + 0.5 × P(Δ)
P(Δ) = 本 episode 最近 256 個有改善的 Δ 中，≤ Δ 的比例（視窗在回合開始時凍結；視窗空時 P = 0.5）
```

- **γ = 0.5，n = 3**（預算 1000 一段約 8 回合，n 不能太大）。另跑 γ = 0（contextual bandit）當消融，看長期有沒有幫助。
- **轉移**：同一個 searcher 編號、同一個 good 位置的下一回合；該段最後一回合為終止狀態。
  注意：good 位置的內容可能被別的 searcher 的子代換掉，這個轉移本身帶有雜訊。
- 沒有結尾獎勵。

## 4. 示範資料（老師）

- 老師＝作弊版（`../oracle/`）：每組交易偷看 4 段**只交換、不突變**的結果，選 Δ 最大的段（同分比 f(child2)），
  再照常突變。只交換的結果是確定的，所以老師的選擇不含突變的運氣。
- 作弊版在 MAP01–06 的天花板：預算 1000 **+9.1%**（29/1）、3000 **+5.9%**（28/2）。
- 收集：在訓練圖的快照上跑作弊版，存下每組交易的 (s, a_E, r, s′)。
- DQfD 不在線上問老師（示範是固定的一批），線上訓練不用偷看，評估量和一般 ring_se 相同。

## 6. 訓練設定

**損失（DQfD）**：

```
J(Q) = J_DQ（1-step Double DQN） + λ1·J_n（n-step Double DQN） + λ2·J_E（大邊界模仿） + λ3·J_L2
J_E  = max_k [ Q(s, k) + l(a_E, k) ] − Q(s, a_E)，l = 0（k = a_E）否則 margin
```

- J_E 只算在示範資料上。它**只要求老師選的段 Q 比其他段高出 margin，不規定 Q 的絕對值**，所以可以和 TD 損失共存。
- λ1 = 1、λ2 = 1、λ3 = 1e-5（DQfD 原設定）；margin = 0.1（原論文 0.8 配 Atari 的獎勵尺度，我們的 Q 約 0–2，所以縮小）。
- **預訓練**：只用示範資料，四項損失一起訓練 10k 次梯度更新。
- **線上訓練**：示範資料永久留在 PER；PER α = 0.4、β 從 0.6 升到 1、自己資料的優先度加 ε_a = 0.001、示範加 ε_d = 1。
- 學習率 3e-4（Adam）、batch 128、replay 100k、target 每 1000 步硬更新、每回合 4 次梯度更新。
- 每個 episode：從 190 張訓練圖抽一張、抽一個快照，跑一段預算 1000 的最佳化。
- 驗證：10 張驗證圖 × 固定快照，每 20 個 episode 一次；保留驗證最佳的 checkpoint，並另外報最後一個。
- 訓練 3 個 seed。超參數寫進 `config.json`（寫程式時建立）。
