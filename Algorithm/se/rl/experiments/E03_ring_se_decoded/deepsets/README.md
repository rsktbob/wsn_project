# E03 / deepsets：監督式 DeepSets 打分網路

網路圖：`../design.svg` 第 ② 部分。

## 輸入（每個候選範圍）

- **範圍內每顆 sensor 一個 token，25 維**（範圍最長 50 顆，超過的補零遮罩）：
  - searcher、good 各 10 維（解碼後）：開關、等級/5、是否轉送節點、轉送量/全網最大、子樹大小/N、
    跳數/最大跳數、耗能/全網最大、緊迫度（全網最短壽命 ÷ 這顆壽命，1＝瓶頸）、覆蓋 target 數 min(c,5)/5、
    只有它覆蓋的 target 數 min(c,3)/3
  - 共用 2 維：剩餘電量 E/E0、離 BS 距離/最大
  - 差異旗標 3 維：開關不同、兩邊都開但等級不同、優先值基因不同
- **範圍外影響 4 維**：範圍外有幾顆的路由經過範圍內（S、G，÷N）；範圍內負責的 target 在範圍外沒有備援的比例（S、G）
- **位置 4 維**：起點/N、終點/N、長度/N、是否跨段
- **全域 10 維**：搜尋進度、searcher 停滯/20、活著 sensor 平均電量、fitness 差距排名、S／G 覆蓋率、
  (S 最短壽命 − G 最短壽命)/較大者、S／G 開啟數/N、兩解基因不同的比例

## 網路

φ：25 → 64 → 64（ReLU，每顆 sensor 共用）→ 平均 ‖ 最大 ‖ 總和÷50（192）
‖ 範圍外 4 ‖ 位置 4 ‖ 全域 10（210）→ 128 → 64 → 1。4 個候選共用同一個網路，選分數最高的。寬 64：41,153 參數。

## 訓練

- 目標：Δ ≤ 1e-12 → 0；Δ > 0 → 0.5 + 0.5 × （Δ 在訓練集所有正 Δ 中的百分位）；4 個候選的 MSE。
- Adam lr 1e-3、batch 512、最多 60 epoch、驗證 MSE 6 次沒進步就停；token 在 GPU 上由回合層級特徵即時組出（`model.gather_tokens`，已確認和 `env.build_batch` 一致）。
- 程式：`model.py`、`capacity.py`、`evaluate.py`（`e03_scorer`、`e03_bottleneck`）。checkpoint：`results/deepsets_w{64,256}.pt`。
