# E01 / Rainbow（含 DQfD 式模仿）

- 演算法：Rainbow（原理見 `../../../algorithms/rainbow.md`），六個元件全開：
  Double ✔、Dueling ✔、PER ✔、n-step ✔（n = 3）、Noisy ✔、Distributional（C51）✔
- 模仿：同 D3QN 版的 DQfD 做法（大邊界模仿＋示範預訓練＋示範永久留在 PER），大邊界損失用分布換算的期望 Q 計算。
- 三種訓練同 D3QN 版：Rainbow（不用示範）／**Rainbow＋DQfD 式模仿（主方法）**／純模仿。
- 框架：PyTorch（版本：2.14.1）
- 狀態：**設計中**

## 1. 輸入狀態

和 D3QN 版完全相同：**60 維一次輸入** = 段 0 特徵 14 ‖ 段 1 14 ‖ 段 2 14 ‖ 段 3 14 ‖ 全域 4（定義見 `../d3qn/README.md` 第 1 節）。

| 類別 | 特徵（維度） |
| --- | --- |
| 每段 14 維 | 有效差異數分格（4）、無效差異數（1）、範圍長度（1）、searcher 開啟比例（1）、good 開啟比例（1）、最低電量（1）、平均電量（1）、瓶頸 sensor 數（1）、耗能占比（1）、單一覆蓋 target 數（1）、區段近期成功率（1） |
| 全域 4 維 | 搜尋進度、searcher 停滯、fitness 差距排名、全網電量 |

## 2. 輸出

- **每段一個回報分布**：51 個 atom，輸出 4 × 51，第 k 組固定代表第 k 段。Q(s, k) = Σ_i z_i p_i(s, k)。
- 支撐範圍 [V_min, V_max] = [0, 2]（每步獎勵在 0–1，γ = 0.5、n = 3 時累積回報約 0–2）；γ = 0 消融改成 [0, 1]。
- Dueling：每個 atom 分別做 V + A_k − mean_k A，再對 atom 做 softmax。
- 選動作：argmax Q；**探索靠 Noisy 層，ε = 0**。

## 3. 獎勵與轉移

和 D3QN 版完全相同：每步獎勵（Δ 的本 episode 百分位）、γ = 0.5、n = 3、轉移＝同 searcher、同 good 位置的下一回合。

## 6. 訓練設定

```
J = 分布式 1-step 損失 + λ1·分布式 n-step 損失（皆用 Double：online 選動作、target 估分布；PER 加權）
  + λ2·J_E（大邊界模仿，用期望 Q(s,k) = Σ z_i p_i 計算；只算在示範資料上） + λ3·J_L2
```

- λ1、λ2、λ3、margin、預訓練、PER 的 ε_a／ε_d、學習率、batch、replay、target 更新、episode 與驗證設計、3 個訓練 seed
  都和 D3QN 版相同，方便比較。
- PER：α = 0.5、β 從 0.4 升到 1（Rainbow 原設定），優先度用分布損失。
- Noisy：σ₀ = 0.5。
- 超參數寫進 `config.json`（寫程式時建立）。
