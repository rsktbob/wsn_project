# 分散式路由 v1 初步實驗

固定所有感測器等級 5、通訊範圍 30、每份控制訊息 128 bits、每個 slot 重建路由。六圖三策略共 18 次確定性實驗，均在 2000 時槽上限前停止。

| 策略 | 平均完成時槽 | 六圖結果 |
| --- | ---: | --- |
| energy_balanced | 55.33 | 56, 51, 54, 63, 56, 52 |
| min_energy | 28.83 | 35, 25, 24, 27, 25, 37 |
| min_hop | 19.33 | 29, 19, 18, 20, 15, 15 |

七項協定/能量測試通過，另檢查 621 個成功時槽的全部節點路徑皆無迴圈且終止於 BS。SensorEncoding 的 SHA256 保持不變。

這是特定參數下的路由原型驗證，非完整論文效能證據；多數實驗因控制或資料能量不足停止。固定需求服務時間不能與同時最佳化感測排程的 Ring-SETS 壽命直接比較。

完整設計與重現命令見 ../../codes/2027WSN/Algorithm/experiment/README.md；config.json 記錄參數，各 JSON 保存逐 slot 下一跳及成本。
